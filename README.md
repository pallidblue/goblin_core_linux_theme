# goblin_core_linux_theme
This linux theme is both inspired by diinki and Yaelokre. I used the retrofuture rice by diinki as a base and then used the wallpaper by GKDeamon (which you can find under the name meadowlark) which I based the color scheme around. 

I changec the waybar settings a bit and added a custom music widget. More might follow in the future. 

The OS that I am using is EndeavorOS. The Config-files were created for Sway - might need adjusting for hyprland.
